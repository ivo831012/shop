# Каса и склад

Приложение за продажби и склад за магазин и заведение. Работи в браузър на компютър, таблет и телефон и може да се инсталира като приложение.

## Какво може

- **Каса:** маркиране с бутони по категории или с баркод скенер, търсене по име, количества, плащане в брой (с ресто) или с карта.
- **Заведение:** маси по зони, отворени сметки, които се плащат по-късно, „За вкъщи“ и „Доставка“.
- **Без интернет:** касата пази каталога и продажбите на устройството и ги изпраща сама, когато връзката се върне.
- **Артикули:** стоки, рецепти, комбо менюта и услуги. Снимка, баркод, мярка, цена, ДДС група, минимална наличност.
- **Рецепти и менюта:** продажбата изписва съставките от склада. Себестойността и надценката се смятат сами.
- **Склад:** доставки (със средно претеглена доставна цена), брак, ревизия и предупреждения за ниска наличност.
- **Отчети:** оборот за деня, в брой и с карта, по часове, най-продавани, по служители, ДДС по групи, сторно.
- **Потребители:** вход с ПИН код и роли (администратор, управител, касиер, склад).

Предстои: фискален принтер Елтрейд и банков ПОС терминал (`server/src/fiscal.js`).

## Пускане

Най-лесно: на Windows щракнете два пъти върху `start-windows.bat`, на Mac или Linux пуснете `start-mac-linux.sh`. Файлът инсталира всичко, добавя примерни данни и отваря браузъра.

Ръчно:

Нужен е Node.js 22.13 или по-нов.

```bash
npm install
npm run build      # компилира интерфейса
npm run seed       # по желание: примерни данни за кафе-магазин
npm start          # http://localhost:3000
```

При първо пускане без примерни данни се създава потребител „Администратор“ с ПИН `0000`. Сменете го от „Хора“.
Примерните данни добавят и: Мария (касиер) `1111`, Георги (управител) `2222`, Деси (склад) `3333`.

За разработка: `npm run dev` пуска сървъра на порт 3000 и интерфейса на порт 5173.

## Базата данни

Собствена база SQLite в един файл: `server/data/shop.db`. За резервно копие е достатъчно да се копира този файл.
Друго място се задава с `SHOP_DATA_DIR`. Часовата зона по подразбиране е `Europe/Sofia` (`TZ`).

## Структура

```
server/   сървър (Fastify) и база данни
  src/app.js      API
  src/stock.js    складова логика: рецепти, комбо менюта, документи
  src/fiscal.js   фискално устройство и ПОС терминал (предстои)
  test/           тестове: npm test
web/      интерфейс (React + Vite)
  src/pages/      Каса, Склад, Артикули, Отчети, Хора, Настройки
```
